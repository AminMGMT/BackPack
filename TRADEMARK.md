## Why this file exists

AGPL-3.0 gives everybody broad rights over the *code*: use it, study it, change
it, redistribute it. It deliberately says nothing about names and logos, and
Section 7(e) of the licence explicitly allows an author to withhold them. So
these are two separate things and they are worth separating clearly:

| | Granted by AGPL-3.0 | Covered by this policy |
|---|---|---|
| Run it, anywhere, for anything | ✅ | |
| Read and modify the source | ✅ | |
| Fork it and publish your fork | ✅ | |
| Sell a service built on it | ✅ | |
| Call your fork "BackPack" | | ❌ |
| Use the BackPack logo or icons | | ❌ |
| Imply your fork is the official BackPack | | ❌ |

Nothing here restricts what you may do with the code. It restricts what you may
call it.

## What you may do without asking

- Say that your project **is based on**, **is a fork of**, or **is compatible
  with** BackPack. Referring to us by name to state a true fact is nominative
  use and nobody needs permission for it.
- Keep the name in the attribution notices — in fact, you must; see `NOTICE`.
- Write about BackPack, review it, teach it, package it under its own name where
  the package is genuinely BackPack and not a modified version.

## What needs a different name

If you publish a **modified version**, it needs a name of its own. Not
"BackPack", not "BackPack Pro", not "BackPack-NG", not a logo that is ours with
the colours changed.

This is the same line Redis, Grafana, Mozilla and most other copyleft projects
draw, and it exists for one reason: when somebody's tunnel breaks, they should
be able to tell whose software it is. A fork carrying the original name makes
every bug report, every security advisory and every "is this safe to install"
question unanswerable.

Rename it, then say plainly what it came from:

> **Based on BackPack by Amin Mohammadi (AminMGMT)** —
> https://github.com/AminMGMT/BackPack

That sentence is required by `NOTICE`, and it is also the whole of what is being
asked. Change the name, keep the credit.

## Getting permission

For anything else — a distribution package, a commercial arrangement, using the
name in a way this file does not cover — ask.

Open an issue at https://github.com/AminMGMT/BackPack/issues.
